# 게시글 목록은 쿼리스트링이 아니라 정적 라우트로 나눈다

자작글과 번역글 목록은 `/posts/authored`와 `/posts/translated` 정적 라우트로 제공하고, `/posts?filter=…`는 쓰지 않습니다. GitHub Pages 정적 배포에서는 쿼리스트링이 무시되고, 페이지네이션은 빌드 타임 `paginate()`로 이미 잘려 있어서 클라이언트에서 거르면 빈 페이지가 생깁니다. 쿼리스트링 URL은 따로 색인되지도 않아서, 자작글을 드러내려는 목적과 맞지 않습니다.

**Considered Options:** 자작글 URL로 `original`·`written`·`mine`도 검토했지만 기각했습니다. 두 목록을 가르는 축은 글의 속성이나 소유권이 아니라 저자가 한 행위(저술했는지, 번역했는지)입니다. 특히 `original`은 번역 블로그에서 "원문"으로 읽힐 수 있습니다.
