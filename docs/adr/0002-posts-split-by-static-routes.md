# 게시글 목록은 쿼리스트링이 아니라 정적 라우트로 나눈다

자작글과 번역글 목록은 `/posts/authored`와 `/posts/translated`라는 별도 정적 라우트로 제공합니다. `/posts?filter=…` 방식은 쓰지 않습니다. 이 사이트는 GitHub Pages에 올리는 정적 빌드라서 쿼리스트링을 처리할 수 없습니다. 페이지네이션도 빌드 타임에 `paginate()`로 전체 글을 잘라 두기 때문에, 클라이언트에서 필터를 걸면 빈 페이지가 생깁니다(예: "6페이지 중 5"인데 글이 0편). 쿼리스트링 URL은 검색엔진이 별도 페이지로 색인하지도 않아서, 자작글을 드러내려는 목적과도 맞지 않습니다.

**Considered Options:** 자작글 탭의 URL로 `original`·`written`·`mine`도 검토했지만 기각했습니다. 두 목록을 가르는 기준은 글의 속성이나 소유권이 아니라 글을 만든 행위(저술했는가, 번역했는가)입니다. 특히 `original`은 번역 블로그에서 "원문"으로 읽힐 위험이 있습니다.
