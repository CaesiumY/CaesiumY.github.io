# 개인정보 처리방침

이 블로그는 정적 사이트입니다. 자체 서버도, 데이터베이스도, 회원가입이나 로그인 기능도 없습니다. 방문자에게 이름이나 이메일 같은 개인정보를 직접 입력받는 양식이 하나도 없다는 뜻입니다.

다만 페이지를 띄우는 과정에서 몇몇 외부 서비스를 거치고, 그 과정에서 방문자의 IP 주소나 브라우저 정보가 각 서비스에 전달됩니다. 어떤 서비스가 관여하는지 아래에 그대로 적어 두었습니다.

## 이 사이트가 거치는 외부 서비스

### 호스팅과 전송

페이지 파일은 GitHub Pages에 올라가 있고, Cloudflare를 거쳐 전달됩니다. 두 서비스는 요청을 처리하기 위해 접속 IP와 User-Agent 같은 표준 접속 기록을 남깁니다. 이 기록은 각 서비스의 정책에 따라 관리되며 저는 열람하지 않습니다.

### 방문 통계 (Google Analytics 4)

배포 환경에 측정 ID가 설정되어 있으면 Google Analytics 4 스크립트가 실행됩니다. 어떤 글이 얼마나 읽히는지 파악하는 용도이며, 개별 방문자를 식별하려는 목적이 아닙니다. Google이 쿠키를 통해 방문 기록을 수집한다는 점은 알아 두시는 편이 좋습니다. 브라우저의 추적 차단 기능이나 광고 차단 확장으로 막을 수 있고, 막아도 글을 읽는 데는 아무 지장이 없습니다.

### 댓글 (Giscus)

댓글 영역은 GitHub Discussions를 기반으로 하는 Giscus로 만들었습니다. 댓글을 남기려면 GitHub 계정으로 인증해야 하고, 남긴 댓글은 이 저장소의 Discussions에 공개로 저장됩니다. 인증과 저장은 전부 GitHub에서 일어나며, 저는 GitHub 계정의 비밀번호나 토큰을 받지도, 저장하지도 않습니다. 댓글을 읽기만 할 때는 인증이 필요 없습니다.

### 웹폰트

본문 글꼴은 jsDelivr(Pretendard)에서, 코드 글꼴은 goorm(Goorm Sans Code)에서 불러옵니다. 글꼴 파일을 받아오는 과정에서 방문자의 IP가 해당 CDN에 전달됩니다.

## 브라우저에만 저장되는 것

아래 값들은 방문자의 브라우저 안에만 남고 서버로 전송되지 않습니다.

- `theme`: 라이트 모드와 다크 모드 중 무엇을 골랐는지 (localStorage)
- `blog-scroll-positions`: 읽던 글의 스크롤 위치. 다시 들어왔을 때 이어 읽기를 제안하는 데 씁니다 (localStorage)
- `backUrl`: 글에서 목록으로 돌아갈 때 어디로 돌아갈지 (sessionStorage, 탭을 닫으면 사라집니다)

브라우저의 사이트 데이터 삭제 기능으로 언제든 전부 지울 수 있습니다.

## 검색

사이트 내 검색은 Pagefind로 구현했습니다. 검색 색인 파일을 브라우저가 내려받아 브라우저 안에서 검색하는 방식이라, 입력한 검색어가 저에게도 다른 어떤 서버에도 전송되지 않습니다.

## AI 에이전트와 크롤러

이 사이트의 모든 글은 자바스크립트 없이 읽을 수 있는 정적 HTML로 제공됩니다. 에이전트를 위한 사이트 안내는 [/llms.txt](/llms.txt)에 있습니다. 크롤러 접근 정책은 [/robots.txt](/robots.txt)를 따릅니다.
